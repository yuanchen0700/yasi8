# brand9 IELTS Speaking Practice App

## 项目说明
IELTS口语练习应用，支持Part 1/2/3题目浏览、音频播放、录音、进度追踪等功能。
Node.js 零第三方依赖后端（`node:http` + `node:sqlite` + `node:crypto` + 自写 SMTP），SQLite 存数据，前端单文件 `index.html`。

## 启动方式

### 1. 本机 Windows（当前主用，2026-08-10 起）
```powershell
$env:BRAND9_PORT='8648'
node server.js
```
- 本地地址: http://127.0.0.1:8648/
- 公网地址: https://ai-answer.devang.top/（cloudflared 隧道 → 127.0.0.1:8648，**不用 frp**）
- 本机 8648 端口常驻由守卫脚本 `D:\cloudflared\start-brand9.ps1` 托管（登录自启、防双开），日常无需手动启动
- 换实验内容时改 8648 端口占用方即可，隧道不用动

### 2. 服务器端 / Linux（frp 部署）
```bash
bash start_project.sh
```
- 本地地址: http://127.0.0.1:8996/
- 公网地址: http://118.89.62.241:8649/（frp 隧道）

### 3. 本地 HTTPS 模式（Windows + ZeroTier，可选）
```bash
bash start_local.sh
```
- HTTPS 地址: https://127.0.0.1:8996/ 和 https://<ZeroTier-IP>:8996/
- 使用 mkcert 签发的证书（10.110.218.198+1.pem），无红字警告

### 端口与环境变量（server.js:25-27）
- `BRAND9_PORT`：监听端口，默认 `8996`（不设时不变），本机跑 8648 靠它
- `BRAND9_TLS=1`：启用 HTTPS（需 mkcert 证书）；不设走 HTTP
- 需 Node.js >= 22.5（`node:sqlite`）；两个实例不要同时跑（抢端口），切换前先停掉旧的

### 2026-08-05 邮箱验证注册（防批量注册）
- **需求**: 注册需邮箱验证，防止随便注册大量账号
- **实现**:
  - 注册流程: 用户名 + 密码 + 邮箱 + 6 位数字验证码
  - 点「发送验证码」后向邮箱发送 6 位数字验证码
  - 验证码 5 分钟内有效（300 秒），60 秒内不可重复发送
  - 重新发送会作废上一个验证码（同邮箱仅存一条）
  - 一个邮箱只能注册一个账号；老用户（无邮箱）不受影响仍可登录
- **邮件配置**: 复用 dw-shop 的 SMTP 配置（读取 `../fun/dw-shop/.env` 的 `DW_SHOP_SMTP_*`，或进程环境变量），无需重复配置

### 2026-09-02 免密直达登录链接（v2.6.0）
- **功能**：管理员在后台为每个账号开放「免密直达」，开放后账号获得独立直达链接（URL `?pass=<token>`），打开链接即自动登录，无需输入密码
- **数据**：users 表新增 `link_open INTEGER DEFAULT 0`（可见性开关）与 `login_token TEXT`（直达链接 token，唯一索引）；token 由 `genLinkToken()` 生成（24 字节 base64url）
- **接口**：`GET /api/me/link`（本人状态）、`POST /api/me/link/gen`（生成/重置）、`POST /api/login/link`（token 换会话）、`GET/PUT /api/admin/accounts/:id/link`（管理员读取/开关）
- **语义**：管理员账号默认开放；关闭可见性即清空 token，旧链接立即失效；未开放账号调用 `/api/login/link` 返回 401
- **前端**：会员中心新增「我的免密直达链接」（仅开放账号可见，可生成/复制）；管理面板用户列表每账号显示免密状态并支持一键开放/关闭 + 复制分发；`admin.html` 同步支持
- **直达打开**：`index.html` 加载时检测 `?pass=`/`?key=` 参数，未登录则静默自动登录并清理 URL 参数

## 技术实现
- Node.js 后端，零第三方依赖；验证码存 SQLite `email_codes` 表，发信用自写 SMTP 客户端（`node:tls`）
- 密码哈希：`crypto.pbkdf2Sync(sha256, 120000)`，与旧 `server.py` 产出的哈希完全兼容（同一 `brand9.db`）
- 前端在注册表单显示邮箱/验证码字段，「发送验证码」按钮带 60 秒倒计时
- 登录接口 `POST /api/login`：凭据错误返回 401 + `{"ok": false, "error": "用户名或密码错误"}`（前端 api() 会忽略 HTTP 状态直接 res.json()）
