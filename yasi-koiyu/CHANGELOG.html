v2.4.02026-08-29

  • 主题新增明暗双主题：右上角太阳/月亮按钮切换，localStorage 记住偏好，默认浅色；页面首屏防闪烁（FOUC）
  • 录音重构为四态状态机 idle / recording / recorded / playing；移除原先独立的「录制我的回答」入口按钮，改由下方固定 172×44 的录音按钮统一承担（空闲时显示「点击开始录制」）
  • 录音进度逐帧填充（rAF）、满 120s 自动停止、录制 <1s 判定为误触并丢弃、长按 3 秒清除录音并重新录制（红色「蓄力」光圈提示）、页面隐藏自动保存停止、开始/停止震动反馈
  • UI参考回答按钮主题化（accent-2 配色，非绿色），仅录完或播放中显示；按钮行在任意状态不位移
  • 提示录制完成后的弹窗提示改为可开关设置（更多菜单内）：默认关闭，每天仅前 2 个新词提示；开启后每次都提示；重录已完成题不再弹窗
  • UI移除右下角浮动版本角标，仅保留页脚不显眼的版本号
  • 适配播放按钮在平板等中等宽度屏幕下放大（62px），避免在大屏上显得过小
  • 进度修复刷新/换设备后回到第 1 题：复习位置（POS_KEY）纳入账号云端同步，登录后拉取云端自动恢复上次进度
  • 体验每天首次进入弹出「欢迎回来」小窗，显示上次复习到第几题，点击可一键继续
  • 总览热力图上方新增「上次复习到：第 X 题」注释，点击直接跳转；浅色下热力图空白格调淡，视觉更轻
  • UI隐藏答案时的遮罩优化：去掉锁形 emoji，改为柔和浅色渐变（贴合主题）、虚线边框提示，白色更轻不刺眼

v2.3.02026-08-23

  • 兼容全部接口、数据库结构、密码哈希算法（PBKDF2 120k 迭代）逐一对齐，现有账号与进度数据（brand9.db）无需迁移直接可用
  • 启动改为 npm start 或 node server.js（需 Node.js ≥ 22.5）
