雅思阅读全解13讲 · 第09讲 配对题专题三：信息匹配（段落信息匹配）（问答精要）

本讲定位：几乎每次考试必遇的无序题，也是多数同学最讨厌的题型。考的不是眼神，而是段落信息处理能力——真正读懂每段在讲什么。核心方法：以五题为界选策略，用"题干每个信息在原文必有解释"来检核。

Q1. 信息匹配题有什么特点？

  • 无序题：题目绝对不按顺序出现（有顺序的话闭着眼睛都能写），一段一题地乱序。
  • 非常分散：一段里顶多 1-2 个信息（有 NB 时一段可能 2 个）。
  • 考察能力：不是四六级长阅读那种"眼神好使"（找相同单词），而是真正理解句子含义 + 识别同义替换形式。
  • 信息可能来自段落中某 1-2 句话，也可能来自 2-3 句话的小总结——不是整段总结。

NB 是什么意思？

  • NB = 有选项可能被用到两次（可能不绝对，做完发现每个选项都不同也完全可能）。

Q2. 做题策略：以五题为界

策略一：题目 > 5 道 → 先读文章，逐段检索

  • 读一段 → 检查剩余题目里有没有来自该段的 → 有就选上 → 再读下一段。
  • 每读一段就像"随机赠送一道题"，不要把它当负担。

策略二：题目 ≤ 5 道 → 先读题干，再通读

  • 先统一处理所有题干，画出关键信息，再带着信息读文章。

Q3. 题干由什么构成？"功能词"有什么用？

  • 题干 = 题干功能词 + 事实信息 + 考点信息（考点和事实信息可能一致）。

功能词分两类

类型 例子 用途
有用的功能词 example、comparison、a personal reaction、why（原因） 对应段落里必须真的出现这种东西
无用的功能词 reference、mention、description、give information about 有它没它一个样，直接忽略
  • 例：题目说"a number of examples" → 你选的段落里必须真的有一串例子，只有一个例子就不对。

Q4. 做题"法宝"是什么？

  • 题干里的每一个信息，在你选的段落里必须有解释。
  • 自问自答检核：这个 example 到底是什么？这个 problem 到底是什么？这个 personal reaction 是谁对什么味道的反应？
  • 每个信息点都要能在原文找到对应解释，才能确认该段。

Q5. 真题全解：基因编辑西红柿（5 题 + NB）

题目：14 抵抗感染的西红柿 / 15 只关注一种西红柿产生的问题 / 16 一系列未种植但未来可作食物的例子 / 17 早期驯化与近期研究的对比 / 18 对基因编辑西红柿味道的个人反应。

A段：驯化历史

  • 3000 年驯化野生西红柿；巴西、中国小组花 3 年重新研究，让它更有营养 → 17 题（early vs recent research 对比）来自 A 段。
  • 但"抵抗感染""例子""问题"都不在 A 段（a 段只提了一个野生作物变食物的说法，不是一个具体例子 → 16 题排除）。

B段：驯化代价

  • 野生西红柿来自南美、像豆子大；人工选育靠基因突变，损失基因多样性，还会获得不想要的变化——超市西红柿失去风味。
  • → 15 题（focusing only on a certain type → 失去风味 problem）来自 B 段。

C段：改良成果

  • 巴西小组：6 次改变 → 三倍大果实、提升可食用部分；恢复红色素（是野生品种 5 倍）。
  • 学者亲口说新西红柿 tasty、味冲 → 18 题（personal reaction）来自 C 段。
  • 中国小组：开发出抗常见病的西红柿 → 14 题（resistant）也来自 C 段 → C 段被 NB 使用两次。

E段：未来食物

  • 一种小果实、成熟就掉地上的作物：难生产、果实小、易摔坏 → 学者改良其尺寸和挂果性 → 有成为经济作物的潜力。
  • 但这是单个例子，不是"一系列" → 排除。
  • 最后一段：三个小组盯上了一系列植物，可能被培养成主流 → 成为食物来源 → 16 题（a number of examples）来自 E 段。

Q6. 常见坑：同词 ≠ 同段

  • 14 题要的是"西红柿抵抗感染"。
  • B 段附近出现过 resistant to disease 的表述，但抵抗的是小麦（wheat）等经济作物，不是西红柿 → 不是答案位置。
  • 关键：看主题词是否一致，别被同义词勾走。

Q7. 通读文章很亏吗？为什么做这题能顺带解题？

  • 不亏：读段落时可以同时解决其他题型（判断题、填空等），把信息匹配当"附加奖励"。
  • 这题的正确率靠的是耐心：笨拙地读懂文章 + 自问自答检核，没有捷径技巧。

Q8. 一句话总结本讲

  • 无序、分散、一段顶多 1-2 个信息（NB 除外）。
  • 策略：>5 题先读文逐段检索；≤5 题先读题。
  • 功能词只信有用的（example/why 等）；题干每个信息在原文必须有解释。
