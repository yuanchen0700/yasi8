雅思听力全解8讲 · 第04讲 表格题 Table Completion（问答精要）

本讲定位：表格题是唯一"4 个 section 都可能出现"的高频小题型。核心就一个反直觉的规律——题目按顺序出，但信息点不一定按顺序，配合读题预测法，表格题拿分不难。

Q1. 表格题出现在哪些 section？难度有区别吗？

  • 可以出现在所有 4 个 section：Section 1/2/3/4 都可能出现（题号 16-20 是 S2，37-40 是 S4）。
  • 不同 section 难度梯度明显：S1 最简单，S4 最压轴。

Q2. 表格题做题第零步是什么？

读题目要求——雅思听力所有填空题都有明确的"填几个单词/数字"限制，下笔前必须看清字数要求，超字数直接判错。

Q3. 表格题做题第一步是什么？

通读表格 + 预测，预测两个方向：

  • 词性：这个空是名词？数字？还是时间？
  • 词义：结合表格里的参考词猜大意（如 location 栏给了 exhibition room、lawn，就猜空的也是地点词）。

预测能让你在音频里"等"答案而不是"找"答案。比如活动名大概率是普通英语单词（不是专有名词），就不用傻等拼写。

词汇彩蛋

  • lawn vs grass：grass 是"草"，lawn 是能野餐的大草坪——词义不同，别混。
  • midday：mid 前缀 = 中间，midday = 中午 12 点（雅思填空答案词）。

Q4. 本讲最重要的规律是什么？（红字重点）

所有雅思听力题目都按顺序出现；但表格里的信息点不一定按顺序出现。

  • 题目顺序：第 1 题说完才说第 2 题，永不跨题号乱序（阅读题型间才可能乱序，听力不会）。
  • 信息点乱序：同一行的 name / location / type / time，音频可能跨列跳着讲——第一行按"名字→地点→类型→时间"走，第二行却先给时间（midday / twelve o'clock）、再给电影名（great migration）。

后果与对策

  • 别在"下一行开头"傻等——答案可能随时跳出来，跟不上就漏题。
  • 应对：耳朵盯住"答案位置"，别盯"表格顺序"；不需要的信息（表格外的闲聊）直接 leave it out，不用管。

Q5. 名字 / 地点是怎么给出来的？有哪些信号词？

  • 名字：几乎都用 called（it's called the great migration / encouraging garden wildlife）——听到 called 后面就是名字答案。
  • 地点：it's on（上映）、take place（发生）——take place in the exhibition room / it's on in theater C。
  • 同一个活动的 3 个信息可能一句话里连排出现（display → 3:45 → on the lawn），一出来就是一串答案。

Q6. 真题答案里有哪些值得记的词？

Animal World 表格题（6 空）：

空 答案 备注
地点 insect house insect 昆虫 + house
类型 lecture 昆虫学家 Dr. David Crocker 的讲座
名字 great migration 非洲大草原动物大迁徙
地点 theater C 见下方"字母编号"
名字 encouraging garden wildlife 教你把鸟类/松鼠吸引到自家花园
类型+时间 display / 3:45 display 展示；时间逢五逢十

国外字母编号的文化背景

老外对数字不敏感：单元楼不叫"1 单元"叫 A 单元，影院厅不叫"1 号厅"叫 theater C。别把 C 听成 Sea（海）——上映地点不可能是"大海电影院"。

Q7. 一句话总结本讲

  • 表格题 4 个 section 都可能出，先看字数要求，再通读预测词性词义。
  • 题目按顺序、信息点乱序——盯住答案位置，called / take place / it's on 是信号词，无关信息直接忽略。
  • 时间永远逢五逢十（3:45 不会考 3:03）；老外用地字母编号（theater C）。
